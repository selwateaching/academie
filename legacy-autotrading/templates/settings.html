Configuration Google Cloud

Pour utiliser l'intégration Gmail, vous devez créer un projet Google Cloud et configurer OAuth 2.0.

1
Créer un projet Google Cloud
Rendez-vous sur console.cloud.google.com et créez un nouveau projet ou sélectionnez-en un existant.
2
Activer l'API Gmail
Dans APIs & Services → Bibliothèque, recherchez Gmail API et activez-la.
3
Créer des identifiants OAuth 2.0
APIs & Services → Identifiants → Créer des identifiants → ID client OAuth 2.0. Type : Application Web.
4
Ajouter l'URI de redirection
Dans les URIs de redirection autorisées, ajoutez : http://localhost:5000/auth/gmail/callback (et votre domaine de production si applicable).
5
Configurer le fichier .env
Copiez le Client ID et le Client Secret dans votre .env : 
GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_client_secret
