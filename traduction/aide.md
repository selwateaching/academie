# Tarjam — guide complet (base de connaissances de l'assistant d'aide)

Tarjam est une application web d'interprétation pour une association qui accueille des personnes étrangères. Elle traduit la voix, le texte et les documents entre le français et d'autres langues, et permet de suivre les personnes (dossiers) et de produire des courriers standards.

## Premier démarrage
- Ouvrir l'adresse de l'application dans le navigateur (Chrome ou Edge sur ordinateur et Android, Safari sur iPhone).
- Si un champ « Code d'accès » apparaît en haut à droite, saisir le code donné par l'association. Il est enregistré sur l'appareil : on ne le redemande pas à chaque conversation. Il ne change jamais tout seul ; il ne change que si le responsable le modifie. Si l'appli affiche « Code d'accès incorrect », le ressaisir. Après 10 mauvais essais, l'accès est bloqué 15 minutes.
- Autoriser le micro quand le navigateur le demande (sinon la voix ne marche pas, mais on peut écrire).
- Pour garder l'appli comme une application : menu du navigateur → « Ajouter à l'écran d'accueil » (ou « Installer »).
- La première ouverture de la journée peut prendre environ 30 secondes (le serveur se réveille). C'est normal.
- Il faut Internet pour traduire. Sans Internet, seules les « Phrases utiles » déjà chargées fonctionnent ; un bandeau rouge « Pas de connexion » s'affiche.

## L'écran d'accueil
1. Choisir **la langue de la personne accueillie** dans la liste en haut (par exemple Arabe algérien). Ce choix est mémorisé.
2. Choisir ensuite une des 7 cartes :
   - **Français → [langue]** : le bénévole parle ou écrit en français ; la traduction s'affiche en gros et est lue à voix haute.
   - **[Langue] → français** : la personne parle ; la traduction française s'affiche.
   - **Deux téléphones** : chacun parle sa langue sur son propre téléphone.
   - **Conversation** : les deux sens sur un seul appareil (quand les deux personnes sont au bureau).
   - **Phrases utiles** : 18 phrases d'accueil toutes prêtes, fonctionnent sans Internet une fois chargées.
   - **Dossiers et courriers** : suivi des personnes et courriers standards.
   - **Document** : traduire, simplifier ou expliquer un courrier, formulaire ou PDF.
3. Le bouton « ← Accueil » (ou « Retour ») en haut à gauche permet de revenir en arrière.
4. Le bouton **🧹 Nouvelle personne** (en haut à droite, icône de corbeille sur petit écran) efface tout : conversation, document, photo, session partagée. À appuyer entre deux personnes accueillies. L'appli efface aussi tout toute seule après 10 minutes sans activité. Cela ne supprime pas les dossiers enregistrés.

## Langues
Darija algérienne, tunisienne, marocaine ; arabe standard ; anglais ; dari ; pashto ; turc ; espagnol ; portugais ; russe ; ukrainien ; bengali ; persan ; ourdou ; hindi ; chinois ; roumain ; italien ; allemand ; polonais ; vietnamien ; albanais ; tamoul ; somali ; amharique.
- Les darijas sont comprises même mélangées avec des mots français, écrites en lettres arabes ou latines. Quand l'appli écrit en darija, elle utilise les lettres arabes et garde les mots administratifs français courants (CAF, préfecture, rendez-vous).
- La reconnaissance vocale du navigateur comprend moins bien les dialectes, et le dari et le pashto sont peu ou pas reconnus à la voix : dans ce cas utiliser le clavier ou l'import d'un message vocal. Le message « langue non reconnue » signifie cela.
- La voix qui lit la traduction est souvent en arabe standard, pas en dialecte ; le texte affiché, lui, est dans le dialecte.

## Français → langue
1. Appuyer sur **🎤 Je parle (français)** et parler, ou écrire dans la zone « Ou écrivez en français… » puis **Envoyer** (ou Entrée).
2. La traduction apparaît en gros, avec le français d'origine en petit dessous. Elle est lue à voix haute si la case « Lire à voix haute » est cochée. Le bouton **🔊 Écouter** la rejoue.
3. Appuyer de nouveau sur le micro pour l'arrêter.
- Parler lentement, par phrases courtes, une idée à la fois.
- **⇄ Inverser** passe à « langue → français » en un clic (cela recommence une conversation vide).

## Langue → français
1. Donner l'appareil à la personne, ou mettre l'appel téléphonique sur haut-parleur près du micro.
2. Appuyer sur **🎤 La personne parle** : l'appli écoute et affiche la traduction française. Appuyer de nouveau pour arrêter.
3. Pour un message vocal reçu (WhatsApp, etc.) : **📎 Importer un message vocal reçu**, choisir le fichier (.opus, .ogg, .m4a, .mp3, .wav). L'appli le transcrit puis le traduit. Cette fonction n'existe que si l'association a activé la transcription de fichiers ; sinon un message l'indique.

## Conversation (un seul appareil, deux personnes au bureau)
- **🎤 Ils parlent** quand la personne parle (traduction en français à gauche, en bleu).
- **🎤 Je parle (français)** quand le bénévole répond (traduction à droite, en vert, lue à voix haute).
- Possibilité d'écrire en français, d'importer un message vocal, de cocher/décocher « Lire à voix haute ».
- Si les deux micros se perturbent, appuyer sur un seul micro à la fois ; l'appli met en pause l'écoute pendant qu'elle parle.

## Deux téléphones
Chacun parle dans son téléphone, dans sa langue ; le message de l'un s'affiche traduit sur l'écran de l'autre.
1. Le bénévole appuie sur **Deux téléphones**. Un **code de session** (6 caractères), un **QR code** et un lien s'affichent. Ce code est différent à chaque session ; il est sans rapport avec le code d'accès.
2. La personne scanne le QR code avec son téléphone (appareil photo), ou le bénévole appuie sur **📤 Envoyer le lien** (par exemple par WhatsApp). Elle n'a rien à installer et n'a pas de code d'accès à saisir.
3. Sur son téléphone la personne choisit sa langue dans la liste (écrite dans sa propre langue) puis appuie sur **OK**.
4. Le bénévole voit « ✅ Personne connectée : [langue] » ; la conversation peut commencer.
5. Chacun appuie sur son 🎤 et parle, ou écrit dans la zone de texte puis ➤. Les messages arrivent en quelques secondes. Sur chaque message reçu, 🔊 permet de l'écouter. La case 🔊 en bas lit automatiquement les messages reçus (cochée par défaut chez la personne, décochée chez le bénévole).
6. **📺 Mode écran** (côté bénévole) ouvre une page en très grand texte (français + langue de la personne), pour une télévision en salle d'accueil, en lecture seule.
7. À la fin : **🧹 Nouvelle personne** ferme et supprime la session. Elle s'efface aussi seule après 3 heures. Ne pas diffuser le lien ou le code. Si le message « Session introuvable ou expirée » apparaît, recréer une session. « La personne n'a pas encore rejoint la session » : attendre qu'elle ait validé sa langue.
- Sur iPhone la voix demande Safari ; Chrome sur iPhone ne gère pas la reconnaissance vocale : écrire.

## Document
1. Choisir le **mode** : **📄 Traduire** (traduction complète + « ➜ En bref » : de quoi il s'agit et que faire), **🧭 Simplifier** (langage très simple : de quoi il s'agit, ce qu'il faut faire, avant quelle date, ce qui se passe sinon), **✍️ Formulaire** (explique chaque case, ce qu'il faut y écrire, un exemple, pièces à joindre, où signer).
2. Choisir le **sens** : « Document → français » ou « Document → [langue de la personne] ».
3. **📷 Prendre une photo** (appareil photo du téléphone), ou **🖼️ Choisir une image ou un PDF**, ou **✍️ Ou collez un texte**.
4. Attendre quelques secondes. Le résultat s'affiche avec des pictogrammes (📅 date, 💶 argent, 📄 papier à fournir, 📍 lieu, 📞 téléphone, ⚠️ urgent, ✍️ signer). **🔊 Écouter** le lit, **📋 Copier** le copie.
- Photo : bonne lumière, document à plat, texte net, cadré. Ce qui est illisible est signalé entre [crochets].
- Toujours vérifier dates, montants et noms sur le document d'origine.

## Phrases utiles
18 phrases d'accueil (bonjour, nom, rendez-vous, s'asseoir, attendre, pièce d'identité, formulaire, signer, répéter, parler lentement, compréhension, enfants, médecin, papiers à apporter, revenir lundi à 10 h, gratuité, utilisation de l'appli, au revoir) traduites dans la langue choisie avec 🔊. Elles se téléchargent automatiquement quand il y a du réseau et restent sur l'appareil : ouvrir l'appli une fois avec du réseau pour chaque langue utilisée.

## Dossiers et courriers
Disponible seulement si l'association a activé les dossiers (sinon le message « Les dossiers sont désactivés » s'affiche). Les dossiers sont chiffrés, protégés par le code d'accès, et supprimés automatiquement après une période d'inactivité (24 mois par défaut).
- **+ Nouveau** : prénom, nom, langue, téléphone (facultatif), statut (En cours / En attente / Clos), prochaine échéance (en rouge si dépassée), remarques. Ne noter que le strict nécessaire.
- La liste se filtre avec la barre de recherche. Appuyer sur un dossier pour l'ouvrir.
- **Ajouter au suivi** : type (rendez-vous, appel, démarche, courrier, note), date, texte → **Ajouter**. Chaque ligne est signée du prénom du bénévole (demandé une fois). La croix ✕ supprime une ligne.
- **🌍 Traduire avec cette personne** : règle la langue du dossier et ouvre la Conversation.
- **✏️ Modifier**, **Clore/Rouvrir le dossier**, **🗑 Supprimer le dossier** (définitif, sur demande de la personne ou à la fin du suivi).
- **✉️ Courrier standard** : choisir un modèle parmi 6 : attestation d'accompagnement, attestation de présence, demande de rendez-vous, transmission de pièces, demande de réexamen, rappel de rendez-vous. Remplir les cases (les noms viennent du dossier, l'en-tête de l'association est automatique), vérifier l'aperçu, puis **🖨️ Imprimer / PDF** (choisir « Enregistrer au format PDF » dans la fenêtre d'impression pour un fichier). **🌍 Traduire pour la personne** ajoute une version traduite à joindre ; seul le courrier en français fait foi. Chaque courrier imprimé est noté dans le journal du dossier. Les modèles sont les mêmes pour tous ; l'association peut les modifier dans un fichier unique.

## Bonnes pratiques
- Parler lentement, phrases courtes, une idée à la fois ; faire des pauses.
- Reformuler et demander « Avez-vous compris ? » (disponible dans Phrases utiles).
- La traduction automatique peut se tromper : pour la santé, la justice, les papiers, faire vérifier (interprète professionnel, personne de confiance).
- Appuyer sur 🧹 Nouvelle personne entre deux personnes.
- Informer la personne que ses mots sont traduits par un service en ligne et qu'aucune conversation n'est enregistrée ; seuls les dossiers le sont, avec son accord.

## Confidentialité
- Les conversations, photos et documents ne sont pas conservés par l'application ; ils sont envoyés à un service de traduction (Anthropic) pour être traduits, puis effacés de l'écran avec 🧹 ou après 10 minutes d'inactivité.
- Seuls les dossiers sont conservés, chiffrés, accessibles avec le code d'accès. Le code est partagé : le changer quand un bénévole quitte l'association.

## Problèmes fréquents
- **Le micro ne démarre pas / « Micro refusé »** : autoriser le micro dans le navigateur (cadenas à côté de l'adresse), utiliser Chrome ou Edge (Safari sur iPhone), ou écrire.
- **« Ce navigateur ne gère pas la voix »** : changer de navigateur ou écrire.
- **« Langue non reconnue à la voix »** : le dari, le pashto et certaines langues ne sont pas reconnus : écrire, ou importer un message vocal.
- **Rien ne s'affiche / « Erreur »** : vérifier Internet ; réessayer.
- **« Code d'accès incorrect »** : ressaisir le code ; **« Trop d'essais »** : attendre 15 minutes.
- **« Le serveur n'a pas encore de clé API »** ou « Les dossiers sont désactivés » : problème de configuration, prévenir le responsable de l'appli.
- **Pas de son** : monter le volume, cocher « Lire à voix haute », appuyer sur 🔊 ; sur iPhone désactiver le mode silencieux.
- **Traduction bizarre** : reformuler avec une phrase plus courte ; en darija, parler sans mélanger trop de langues.
- **L'appli est lente au premier lancement** : le serveur se réveille (environ 30 secondes).
- **L'import de message vocal est refusé** : cette option doit être activée par le responsable.
- **Photo illisible** : refaire avec plus de lumière, document à plat, ou coller le texte.
- **La personne ne voit pas sa langue** : choisir la plus proche (par exemple arabe standard) ou utiliser l'écriture.

## Ce que l'assistant ne fait pas
Il explique le fonctionnement de Tarjam. Il ne donne pas de conseil juridique, médical ou administratif, et ne remplace pas un interprète professionnel.
