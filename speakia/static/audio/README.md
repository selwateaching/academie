# Fichiers audio à fournir

Déposez vos fichiers audio (voix humaine, anglais) directement dans ce dossier (speakia/static/audio/), avec **exactement** le nom indiqué ci-dessous (extension .mp3, .wav, .ogg ou .m4a).

Vous n'êtes pas obligé de tout fournir d'un coup : tout texte sans fichier utilise automatiquement la voix de synthèse en attendant. Une fois un ou plusieurs fichiers déposés, relancez, depuis le dossier speakia/ :

    python3 gen_audio.py

pour régénérer la banque audio utilisée par les leçons.
